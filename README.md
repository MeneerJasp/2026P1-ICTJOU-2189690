# ICT in jouw omgeving

Welkom in jouw repository voor de cursus **ICT in jouw omgeving**. In deze repository vind je alle projectbestanden die je nodig hebt voor de opdrachten en oefeningen van deze cursus. Het is de bedoeling dat je jouw uitwerkingen in deze repository opslaat en bijhoudt.

Alle aanpassingen die je in deze repository maakt, kun je _committen_ en _pushen_ naar de remote repository op Gitlab. Zo is alles veilig opgeslagen en kun je er altijd bij, maar zo kunnen docenten ook meekijken met je voortgang. Ook tijdens de gesprekstoets zullen de inhoud van je repository en hoe vaak je _commits_ en _pushes_ hebt gedaan worden bekeken.

## Structuur van de repository

De repository is als volgt gestructureerd:
- `README.md`: Dit bestand, waarin je informatie vindt over de repository en de cursus.
- `.gitignore`: Een bestand dat aangeeft welke bestanden en mappen niet naar de Git-repository moeten worden gecommit.
- `niveau1`: Een map met projecten van niveau 1 (waaraan je werkt in weken 2 en 3).
- `niveau2`: Een map met projecten van niveau 2 (waaraan je werkt in weken 4 en 5).
- `niveau3`: Een map met projecten van niveau 3 (waaraan je werkt in weken 6 en 7).
- `niveau4`: Een map met projecten van niveau 4 (waaraan je werkt in week 8).
