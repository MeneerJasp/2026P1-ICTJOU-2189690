# Ontwerp Vind it!

## Inleiding

Dit document beschrijft het ontwerp van Vind it!. Dit ontwerp biedt de technische basis voor de realisatie van de applicatie.

## Technische eisen

- De applicatie moet geschreven zijn in Python.
- De applicatie moet gebruik maken van een MariaDB-database voor het opslaan van gegevens.
- De applicatie moet een command-line interface (CLI) hebben voor interactie met de gebruiker.
