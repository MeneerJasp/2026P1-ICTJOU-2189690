# Analyse

## Introductie

In dit document worden de functionale en niet-functionele eisen van een workouttracker beschreven. Deze workouttracker kan gebruikt worden om informatie over workouts in vast te leggen. Op basis van de ingevoerde workouts kunnen enkele statistieken worden getoond en een gefilterde lijst met alle ingevoerde workouts.

## Gebruikersinterface

De applicatie is draait in een terminalscherm. De gebruiker krijgt een menu te zien en kan hier door invoer van een cijfer een keuze in maken.

Hieronder staan van enkele schermen ontwerpen.

### Schermontwerp menu

```text
+--------------------------------------+
| WORKOUTTRACKER                       |
|                                      |
| Maak je keuze:                       |
| 1. Toon alle workkout                |
| 2. Toon alle hardloop-workouts       |
| 3. Toon alle krachttraining-workouts |
| 4. Toon alle andere workouts         |
| 5. Workout invoeren                  |
| 6. Totale duur tonen                 |
| 7. Toon alle gebruikte workouttypes  |
| X. Afsluiten                         |
+--------------------------------------+
```

### Schermontwerp overzicht

```text
2025-01-01 07:15:00 - Hardlopen - 50 minuten
2025-01-02 07:15:00 - Hardlopen - 120 minuten
2025-01-03 07:15:00 - Krachttraining - 50 minuten
2025-01-04 07:15:00 - Zwemmen - 60 minuten
```

### Schermontwerp gebruikte workouttypes

```text
hardlopen
krachttraining
yoga
zwemmen
```

### Schermontwerp totale duur van workouts

```text
Totale duur van workouts: 4 uur en 20 minuten.
```
